Somente QA

Eventos do confronto

Os eventos usam o runtime real da Diversão. No iPhone/WebKit, o teste abre a página pública em modo isolado para não manter Admin + iframe disputando memória/GPU; nenhuma animação, áudio ou arquivo do evento é removido.

Caos Perfeito: o roster cadastrado possui menos de seis classes distintas. Para testar apenas a apresentação visual desse evento, o laboratório cria nomes de classe temporários dentro do preview. Nada é salvo nem apresentado como dado real do jogo.

Fluxo e recuperação

No desktop, o preview continua embutido. No iPhone, cada teste usa uma execução isolada em tela cheia e retorna ao laboratório sem deixar o iframe pesado residente.
