# Identity Institutional Roles V12

Founder e Admin usam o Meu Perfil como identidade institucional, não como participantes da progressão Echo Scouts.

- Founder não exibe pontos, ranks, missões, especialidades ou contribuições comunitárias.
- Admin não exibe progressão comunitária e recebe uma insígnia funcional derivada de `echo_admin_context`.
- A função administrativa é exercida no painel; o perfil apenas representa essa autoridade já confirmada pelo servidor.
- Heróis, Equipamentos, Conteúdo, Qualidade, Inteligência e Moderação possuem identificação funcional própria.
- Membros comuns continuam com Echo Scouts, pontos, especialidades, missões e Echo Research.

Nenhuma autoridade é criada ou inferida pelo cliente.
